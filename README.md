# Introduction to Collaborative Coding

A short hands-on introduction to the tools used for collaborative scientific coding: Linux and Bash, Python environments with conda, and version control with Git and GitHub.

## Notebook

- [Read the notebook](IntroductionToCollaborativeCoding.ipynb) (rendered by GitHub)
- Run it online: [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/USER/REPO/blob/main/IntroductionToCollaborativeCoding.ipynb)

## Contents

- Linux, Bash and the terminal
- Processes, scripts and environments
- Python and conda environments
- Git and GitHub

## Getting started

```bash
git clone https://github.com/Dario-Maglio/CollabCoding.git
cd CollabCoding
```
